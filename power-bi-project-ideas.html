Power BI and Excel project ideas, with the datasets to build them

A Power BI or Excel project should show clean data, the right measures and a dashboard a manager would actually open. These ideas each come with a messy dataset on KOJOH and tasks that end in a two page dashboard.

4. E-commerce discount and profitability analysis

₹249 · Hard · Python, SQL, Excel, Power BI

You will practise: Contribution margin by month and category; Returns, RTO and COD leakage; Marketing channel ROAS; Listing manager performance ranking.

How to make any project stand out

  • Clean in Power Query or with lookups before building visuals.
  • Use measures for anything that should react to slicers.
  • Build one page for the overview and one for the detail a manager acts on.
  • Add a short note on what the dashboard tells the business.

Questions

Where can I find datasets for these projects?

Each idea on this page links to a KOJOH project with its own messy dataset, tasks and a data dictionary. Kaggle and government open data portals are other good free sources.

Are these projects good for a portfolio?

Yes. Each one ends with cleaned data, answered business questions, a dashboard and a one page recommendation, which is what recruiters look for. Paid KOJOH projects give every buyer a personal brief, so your answers are your own.

Is the data real?

No. Every KOJOH dataset is synthetic, built to behave like real Indian business data, including the mess.
