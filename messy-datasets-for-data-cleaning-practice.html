Messy datasets for data cleaning practice

In short: Clean datasets teach you charts; messy ones teach you the job. Every KOJOH dataset below comes with real-world problems built in, and each problem is listed so you know exactly what to find and fix. Practise in SQL, Python, Excel or Power Query, then carry on to the analysis and the dashboard.

Start with a free messy datasetAll projects

What kind of mess will you find?

  • Duplicate rows: double-printed bills, retried events, overlapping exports.
  • Mixed formats: dates written three ways, amounts with currency signs, Yes/Y/1 in one column.
  • Inconsistent names: the same city, product or vendor spelled differently.
  • Missing and impossible values: blanks, zeros that mean unknown, negative quantities.
  • Broken keys: IDs that do not join across files.

1. Aai's Tiffin Service: A Pune Home Kitchen's Order Sheet

Frequently asked questions

Where can I find messy data to practise data cleaning?

Every KOJOH project ships with deliberately messy raw files: duplicate rows, mixed date formats, inconsistent names, missing values and broken join keys. Each problem is listed on the project page so you know what to look for.

Is there a SQL dataset with duplicate records?

Yes. Several KOJOH datasets include exact and near duplicates, such as double-printed bills, retried app events and overlapping monthly exports, which you remove with GROUP BY, ROW_NUMBER() or DISTINCT ON.

Which messy dataset is best for a Power BI dashboard?

Pick one with dates, a category and a money column, so you can clean it in Power Query and then build trends and breakdowns. The free starters are a good first step.

Is the data real?

No. Every row is synthetic, built to behave like real Indian business data, including the mess.
